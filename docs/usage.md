# 使用指南

## 从空白家谱开始

1. 用初始管理员登录；公网使用前建议在账号菜单中修改管理员密码。
2. 设置家谱名称、简介与资料来源说明。
3. 添加一位已知家人，再从其档案添加父母、配偶或子女。
4. 邀请亲属加入，按需要分配编辑或查看权限。

首次启动没有演示人物或既有关系。暂不清楚的信息可以留空，并标记为待核实，不必为了让图形完整而填入猜测。

## 父母、配偶与子女

系统使用两种关系：父母子女、配偶。关系表单不区分亲生、收养、继亲或其他血缘类别。

从人物档案添加子女时，会按已有配偶关系预选父母；提交前可改选或清除另一位家长。多位配偶时应核实选择，不能仅凭姓名或性别推断父母关系。已有子女关系不会因为后来补填配偶而全部自动重写。

## 世代怎么填

“世代”是家谱记录中的代数，例如明确以某位祖先为第 1 代，其子女填第 2 代、孙辈填第 3 代。没有统一起点或资料不确定时留空。

关系图按实际父母关系从上往下分层。手填世代与父母层级不一致时，以提示方式帮助核对，不会自动改掉档案中的历史记录。避免同一家谱各自从不同人物重新计算第 1 代。

## 阅读关系图

配偶尽量并排，男左女右；子女按家庭组织。可选择中心人物和显示代数，折叠暂时不需要展开的家庭，再拖动、缩放查看。

同一人物出现在多个家庭时，图上可能使用引用表示；引用指向同一档案，不是额外新建的人物。不同父母组合属于不同家庭，请先检查关系是否正确，再判断布局是否异常。

## 协作与分享

权限只区分可编辑和仅查看。管理员拥有编辑权限并管理账号；编辑账号可以维护完整家谱；查看账号可以阅读完整人物资料和附件，但不能修改。邀请链接供接收者注册使用，不要公开张贴。修改记录保留操作者及前后内容，便于核对；同时编辑同一记录遇到冲突时，刷新后确认他人改动，再重新提交。

受邀成员打开链接后登记姓名和手机号码。系统默认用姓名作为用户名、手机号码作为初始密码；成员可用中文姓名或手机号码登录，不强制首次登录修改密码。同名成员仍可用各自手机号码登录。管理员也可直接“新建账号”，并把普通成员密码重置为其手机号码。成员自行修改的密码至少 6 位。

只读分享链接不设置人物或家庭范围，有效期可选 1 天、7 天或 30 天，并可随时撤销。有效链接显示完整家谱资料和附件，但不能写入数据；发送前请确认接收者可信，因为链接可以继续转发。

## 导入、导出与附件

使用系统提供的 Excel 模板或符合字段格式的表格，先预览再确认导入。导入前建议备份，同名不一定是同一人。Excel / JSON 导出方便整理与迁移，但完整恢复仍应使用包含数据库和附件的数据目录备份。

图片支持 JPEG、PNG、WebP，文献支持 PDF。人物有照片时，最新上传的图片会作为关系图卡片和右侧详情中的头像；没有照片时保持文字卡片和姓氏图章样式。上传前去掉与家谱无关的个人信息。关系图可导出 PNG，或通过浏览器打印保存 PDF。
